UI sounds — replace with your own files (same names):

  nav.mp3    — navigation (optional, clicks use click.mp3)
  click.mp3  — buttons and general clicks
  play.mp3   — start playback
  pause.mp3  — pause playback
  like.mp3   — like / unlike

Sound style presets (Soft, Crisp, Warm, Minimal) change built-in tones
when custom files are missing.

Volume: Settings → Appearance → Sound volume slider.
